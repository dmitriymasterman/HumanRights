# Заявка на справку в отдел кадров

Статический одностраничный сайт с формой заявки на кадровую справку. Для работы
не требуются сервер, база данных, сборщик или установка зависимостей: разметка,
стили, логика и SVG-иконки находятся в [`index.html`](./index.html).

## Локальный просмотр

Сайт можно открыть напрямую из файловой системы или запустить простым статическим
сервером:

```bash
python3 -m http.server 8000
```

После этого страница будет доступна по адресу <http://localhost:8000/>.

## Публикация на GitHub Pages

1. Откройте **Settings → Pages** в репозитории GitHub.
2. В разделе **Build and deployment** выберите **Source: Deploy from a branch**.
3. Выберите ветку, содержащую опубликованный коммит (обычно `main`), и папку
   **`/ (root)`**.
4. Нажмите **Save** и дождитесь завершения деплоя в разделе **Actions**.

Файл `.nojekyll` отключает обработку Jekyll. Главной страницей служит корневой
`index.html`, а внешние или абсолютные локальные пути не используются, поэтому
сайт одинаково работает как на доменном, так и на проектном адресе GitHub Pages.
